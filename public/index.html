Backend REST API · Sports & Outdoor Gear Rental

Rent gear. Track every mile it travels.

GearUp is the API behind a marketplace where customers rent tents, bikes and climbing kit from independent providers — full order lifecycle, atomic stock control, and Stripe checkout baked into every route. Built with Node.js, TypeScript, Express and Prisma on PostgreSQL.

02 / WHO'S ON THE TRAIL

Three roles, one platform

Every protected route is gated by role at the middleware layer, before a controller ever runs.
Role 01
Customer
Browses gear, places rental orders, pays through Stripe, tracks status, and leaves a review once the gear is back.
Role 02
Provider
Lists and manages their own inventory, and moves incoming orders forward — confirm, hand off, mark returned.
Role 03
Admin
Oversees every user, listing and order platform-wide, manages categories, and can suspend an account.
03 / TRAIL MAP

One order, start to return

The exact state machine enforced server-side — no order can skip a waypoint.
