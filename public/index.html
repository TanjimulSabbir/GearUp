ABOUT THIS API

This is the backend service powering MiniSocial — a mini social media application supporting user authentication, posts with tags, comments, likes, and real-time push notifications delivered via Firebase Cloud Messaging.

Built with a token-based auth flow (short-lived access tokens + HTTP-only refresh cookies), role-based access control (USER / AUTHOR / ADMIN), and a relational data model connecting users, posts, comments, likes, and notifications end-to-end.
